AOLO Driver App

About the Project

AOLO Driver App is a mobile application developed using React Native to simplify and manage driver-related delivery operations. The application provides a user-friendly interface that allows drivers to access their accounts, scan barcodes, and manage delivery activities efficiently.

The frontend is developed using React Native, while the backend is powered by PHP Laravel with REST API integration.

Technologies Used

* React Native
* JavaScript
* PHP Laravel (Backend)
* REST APIs
* Git & GitHub

Key Features

* Driver Login and Authentication
* Barcode Scanning
* Driver Dashboard
* Delivery Management
* User-friendly Interface

Project Structure

* Frontend: React Native
* Backend: PHP Laravel
* API Communication: REST APIs

Purpose

The main objective of this project is to develop a reliable and easy-to-use mobile application that streamlines driver operations and improves delivery management.

Development Status

Currently under development.
